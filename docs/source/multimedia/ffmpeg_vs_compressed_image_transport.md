# ROS 2における映像伝送：FFmpegとCompressed Image Transport

遠隔操作（テレオペレーション）を行うロボットシステムにおいて、カメラ映像の低遅延かつ高品質な伝送は極めて重要です。ROS 2 Jazzy環境においては、標準的な`compressed_image_transport`に加え、`ffmpeg_image_transport`の利用が検討されています。

FFmpegベースの伝送では、H.264やHEVC（H.265）といった高度なビデオコーデックを利用できるため、ネットワーク帯域の消費を大幅に削減できます。しかし、HEVC等の最新コーデックは圧縮効率に優れる反面、エンコード・デコード処理に計算リソースを要し、環境によっては動作が不安定になるリスクを含んでいます。

現時点では、WebRTCを用いたストリーミングが遅延の観点では最適ですが、セットアップの煩雑さから一般的なROS 2パッケージとしては敷居が高いとされています。そのため、実運用においては、システムの安定性と帯域制限のトレードオフを考慮し、実績のあるH.264コーデックを`ffmpeg_image_transport`で利用するアプローチが、堅実な選択肢となります。
