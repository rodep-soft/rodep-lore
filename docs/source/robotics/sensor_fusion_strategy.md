# センサーフュージョンと自己位置推定の戦略

ロボットのナビゲーションにおいて要となる、自己位置推定（Localization）のためのセンサー情報統合について解説します。

## 各センサーの特性と限界

エンコーダから得られるオドメトリ（車輪の回転量からの推定位置）は、車輪の滑りや床面の状態によって誤差が蓄積します。また、IMU（慣性計測装置）から得られる角速度を単に積分するだけでは、センサ特有のドリフト現象により時間経過とともに致命的な誤差を生じます。

## フィルタリングと統合

精度の高い自己位置推定を行うためには、これら現実のノイズを含んだセンサー値を適切に処理する必要があります。

1.  **IMUのフィルタリング**: 単純なローパスフィルタ（LPF）だけでなく、Madgwickフィルタなどを適用して、加速度計とジャイロスコープの値を組み合わせ、より信頼性の高い姿勢（クォータニオン）を算出します。
2.  **カルマンフィルタ（EKFなど）**: 複数のセンサー（エンコーダ、IMU、場合によってはGPSなど）の値を統合し、予測と観測を繰り返すことで、確率的に最も確からしい状態を推定します。

## Lidarへの依存

エンコーダとIMUのみで精緻な位置推定を行うことには限界があるため、最終的にはLidarを用いたスキャンマッチング（例: KISS-ICPやSLAM Toolboxなど）に位置推定の大部分を依存する方針が現実的です。その際、IMUのデータはローリングやピッチング（斜面での姿勢変化）の補正や、Lidarの点群の歪み補正に限定して使用するなど、各センサーに割り当てる役割の比重（共分散）を適切に設計することが求められます。
