# STM32開発におけるHALとLL、および通信アーキテクチャ

組み込み開発、特にSTM32マイクロコントローラを使用する際のライブラリ選定と、外部PC（ROS2環境）との通信手法について考察します。

## HAL (Hardware Abstraction Layer) と LL (Low-Layer)

STM32向けに提供されているHALは、様々なペリフェラルを汎用的に扱うための抽象化層を提供しますが、その分オーバーヘッドが生じます。処理速度がシビアに要求される場面や、ハードウェアの機能を極限まで引き出したい場面においては、レジスタ操作に近いLLを使用する方がパフォーマンス面で有利です。特にDMA（Direct Memory Access）やタイマ割り込みなどを緻密に制御するスキルは、ロボティクスの足回り制御などにおいて必須となります。

## micro-ROSの適用可能性

micro-ROSをマイコン上に実装することで、シリアル通信を介して直接ROS2ネットワークに参加させることが可能になります。しかし、実装の煩雑さやオーバーヘッドを考慮すると、マイコン側では純粋にセンサ値の取得とモータ制御（LLを使用した高速な処理）に専念させ、PC側でシリアル通信を受け取ってROS2のトピックとして配信するラッパーノードを作成する方が、システム全体としてシンプルかつ堅牢になる場合が多いです。
