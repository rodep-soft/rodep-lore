# IMUのドリフト現象とMEMSセンサーのノイズ特性

慣性計測装置（IMU）を用いた姿勢推定やオドメトリの算出において、センサードリフトは避けて通れない課題です。特に角速度（ジャイロセンサー）の出力を積分して角度を求める際、センサー自体が持つ微小なバイアスノイズが時間とともに蓄積され、積分誤差として増大します。

近年、MEMS（Micro Electro Mechanical Systems）技術の発展によりIMUは極めて小型化されました。しかし、物理的な質量が減少することで、外部の振動や熱に対する感受性が高まり、相対的にノイズレベル（SNR：信号対雑音比）が悪化する傾向にあります。

このドリフト問題に対処するためには、ジャイロセンサー単体の値に依存するのではなく、加速度センサーや地磁気センサーのデータを組み合わせたセンサーフュージョン（例：カルマンフィルタやマホニーフィルタ）の実装が必須となります。正確なシステムモデリングとノイズ特性の事前評価（アラン分散分析など）を行うことが、信頼性の高いロボットナビゲーションの第一歩となります。
