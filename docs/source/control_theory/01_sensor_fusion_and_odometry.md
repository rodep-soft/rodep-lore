# センサフュージョンと自己位置推定の理論・実践

ロボティクスにおいて、自己位置推定（オドメトリ）は全ての自律移動の基盤となります。本稿では、IMU（慣性計測装置）、エンコーダ、Lidarを用いたセンサフュージョンの設計思想から、クォータニオンを用いた運動学の基礎、そして実機開発において直面するドリフト問題やセンサの限界について詳細に解説します。

## 1. センサフュージョンの基本思想

ロボットの移動量は、単純な指令値（例えば「前方に速度 $v$ で3秒間移動せよ」というオープンループな制御）からは正確に推定できません。ロボットには慣性が存在し、床の摩擦係数の変化やスリップなどの外乱が常に作用するためです。したがって、エンコーダやIMUといったセンサから得られる「現実の値」を観測し、閉ループ（Closed Loop）系として状態推定を行う必要があります。

しかし、各センサにはそれぞれ異なる特性の誤差（ノイズやドリフト）が含まれます。
- **エンコーダ**: 短期的な並進移動の計測には優れますが、車輪の空転やスリップにより累積誤差が発生します。
- **IMU**: 高周期での角速度や加速度の取得が可能ですが、積分によるドリフト（特にバイアス誤差の蓄積）が顕著です。
- **Lidar**: 環境の幾何的特徴に基づき高精度な位置姿勢を提供（スキャンマッチング）しますが、計算負荷が高く、特徴のない環境（長い廊下など）では推定が破綻するリスクがあります。

これらの異なる特性を持つセンサ出力を統合し、誤差分散を最小化するための数学的枠組みがカルマンフィルタ（Kalman Filter）や各種非線形オブザーバです。

## 2. IMUの特性とドリフトの数理

IMUから得られる角速度 $\omega$ を積分して姿勢を求める際、単純な時間積分では誤差が急速に増大します。「角速度を積分すると積分誤差分のエラーが出る」というのは表面的な理解に過ぎず、実際にはセンサのバイアス（定常誤差）やホワイトノイズが非線形な姿勢表現の更新において複雑に伝播します。

加速度計から得られる観測値ベクトル $a_m$ と、真の加速度 $a_t$、重力ベクトル $g$、バイアス $b_a$、観測ノイズ $\eta_a$ の関係は以下のようになります。
$$ a_m = R^T (a_t - g) + b_a + \eta_a $$
ここで $R$ は世界座標系からセンサ座標系への回転行列です。重力ベクトルを利用してピッチ角やロール角を補正することは可能ですが、ヨー角（ヘディング）は重力軸回りであるため、加速度計だけでは可観測性がありません。

## 3. クォータニオンを用いた姿勢の運動学

3次元空間における姿勢表現には、特異点（ジンバルロック）のないクォータニオン $q = [q_w, q_x, q_y, q_z]^T$ が広く用いられます。
角速度 $\omega = [\omega_x, \omega_y, \omega_z]^T$ が与えられたとき、クォータニオンの時間微分は次式で与えられます。

$$ \dot{q} = \frac{1}{2} q \otimes \begin{bmatrix} 0 \\ \omega \end{bmatrix} $$

離散時間における更新を考える際、微小回転ベクトル $v = \omega \Delta t$ を用いてクォータニオンの指数写像を計算します。
$$ \Delta q = \cos\left(\frac{\|v\|}{2}\right) + \frac{v}{\|v\|} \sin\left(\frac{\|v\|}{2}\right) $$
ここで、テイラー展開による一次近似を適用すると、計算負荷を下げつつ十分な精度で更新計算を実装することが可能です。この一次近似の数理的背景を理解せずにライブラリのAPIを叩くだけでは、後述する発散や特異な挙動のデバッグが困難になります。

## 4. フィルタリングの実装と限界

ドリフトを防ぐための古典的な手法として、ローパスフィルタ（LPF）を用いた高周波ノイズの除去や、Madgwickフィルタの実装が挙げられます。

### Madgwickフィルタの導入
Madgwickフィルタは、勾配降下法を用いて加速度計（および地磁気センサ）の観測値から姿勢の最適推定値を逐次的に計算し、ジャイロスコープによる積分結果とフュージョンする軽量なアルゴリズムです。

```cpp
// Madgwickフィルタの更新ステップの一部（擬似コード）
void updateMadgwick(float gx, float gy, float gz, float ax, float ay, float az) {
    // 加速度ベクトルの正規化
    float norm = sqrt(ax*ax + ay*ay + az*az);
    ax /= norm; ay /= norm; az /= norm;

    // 目的関数（重力方向との誤差）の勾配計算
    // ...
    // クォータニオンの更新（ジャイロの積分と勾配降下のフュージョン）
    qDot1 = 0.5f * (-q1*gx - q2*gy - q3*gz) - beta * s0;
    qDot2 = 0.5f * ( q0*gx + q2*gz - q3*gy) - beta * s1;
    // ...
}
```

しかし、実地における運用では、これらのフィルタ単体では限界があります。過去のプロジェクトにおいても、「IMUとエンコーダだけで何とかなると思っていた」という設計は破綻を迎えました。エンコーダは車輪のスリップに弱く、IMUはヨー角のドリフトを抑えきれないためです。

## 5. 失敗事例と実践的対策：Lidarへの依存度引き上げ

エンコーダとIMUのみのオドメトリに限界を感じた結果、Lidarを用いたスキャンマッチング（Lidarオドメトリ）に主軸を移す方針への転換が行われました。

具体的な対策として、拡張カルマンフィルタ（EKF）において以下のような共分散行列のチューニングを実施しました。
1. **エンコーダへの信頼度低下**: エンコーダから得られる並進速度（`linear.x`）の観測ノイズ共分散を意図的に大きく設定し、モデルへの寄与（重み）を限界まで下げました。これにより、スリップ時の誤った位置推定を防止します。
2. **IMUの限定的利用**: IMUから得られる角速度は高信頼なものとして全軸を使用しつつも、絶対的な姿勢（Orientation）に関しては、ピッチ角とロール角（坂道などの傾斜補正用）のみを採用し、ヨー角の絶対値はLidar側に依存する構成としました。

このようなセンサ特性の深い理解に基づいたフュージョン設計こそが、ロバストな自律移動システム構築の鍵となります。
