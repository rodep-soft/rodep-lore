# ハードウェア設計におけるEMI対策と信号品質

電子制御システムが高度化し、動作周波数が向上するにつれて、電磁干渉（EMI）の抑制と信号品質（シグナルインテグリティ）の確保は、ハードウェア設計において避けて通れない重要な課題となっています。本稿では、基板設計の基礎から高速信号線のルーティングまで、実践的なアプローチを整理します。

## 電源品質の確保とバイパスコンデンサの適切な配置

マイコンやセンサを安定して動作させるための大前提は、クリーンで安定した電源供給にあります。各ICの電源ピン直近に0.1uFや10uFの積層セラミックコンデンサを配置することは、高周波ノイズをバイパスするための基本中の基本です。ここで重要なのは、単に回路図上にコンデンサを描くことではなく、基板上での物理的な配置です。

コンデンサの寄生インダクタンス（ESL）を最小限に抑えるため、ICの電源ピンとグラウンドピンに対して可能な限り短い経路で接続する必要があります。また、基板設計においては、多層基板を利用してベタグラウンド（グラウンドプレーン）を広く確保することが推奨されます。高周波信号のリターン電流は、信号線の直下を流れる性質があります。リターンパス（電流の帰り道）をスリットなどで分断せず、連続的かつ最短なものにすることで、ループ面積が最小化され、放射ノイズ（EMI）を劇的に抑制することが可能となります。

## 高速信号線のルーティングと波形整形

USBやCAN、高速なSPIやイーサネットといった信号を基板上で配線する際は、伝送線路としての特性を考慮する必要があります。特に差動信号であるUSBやCANでは、ペア配線の長さを厳密に等しくし、規定の特性インピーダンス（USBであれば90オーム、CANであれば120オームなど）を満たすよう、パターン幅と間隔を計算して配線することが求められます。

さらに、現代の高速なマイコンから出力されるデジタル信号は、立ち上がりや立ち下がり（スルーレート）が非常に急峻です。これが原因で高調波ノイズが発生したり、配線のインピーダンス不整合による信号反射が起きたりすることがあります。このような場合には、送信側の出力ピン直近にダンピング抵抗（数十オームの直列抵抗）を挿入することでスルーレートを適切に緩和し、オーバーシュートやアンダーシュートを防ぐというアナログ的な視点も欠かせません。

システム全体のトラブルシューティングにおいては、オシロスコープを用いて実際のアナログ的な電圧波形の品質（リンギングやノイズの有無）を観測し、同時にロジックアナライザでデジタル的なプロトコルの正当性を確認するという、両眼視的なデバッグアプローチが問題解決の最短ルートとなります。論理と物理の両面から現象を捉えることが、安定したハードウェア開発の要諦です。
