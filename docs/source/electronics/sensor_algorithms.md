# センサー信号処理と実践的アルゴリズム

実世界の物理現象を捉え、マイコン上で意味のあるデータとして処理するためには、センサとの確実な通信から、高度な信号処理アルゴリズムの実装まで、幅広い知識が要求されます。本稿では、システムをより堅牢で正確なものにするための実践的な知見を整理します。

## 通信の確実性：I2Cバスのロックアップ対策と状態確認

IMU（慣性計測装置）や環境センサにおいて広く用いられるI2C通信ですが、ノイズやマイコンのリセットタイミングなどにより、通信状態が不安定になることが少なくありません。このような場合、起動後に直ちにレジスタへアクセスするのではなく、まず `HAL_I2C_IsDeviceReady()` などの関数を使用してデバイスの準備が完了しているかを確認する手順を踏むことが重要です。

さらに、I2C通信特有の致命的な問題として、スレーブデバイスがSDAラインをLowに引き込んだままハングアップする「バスのロックアップ」現象が存在します。これを防ぐ、あるいは復旧させるための堅牢な実装として、マイコン側でSCLピンをGPIOとしてソフトウェア制御し、クロックを数回トグルさせることでスレーブデバイスの状態をリセットするリカバリ処理を組み込むことが推奨されます。この処理を初期化ルーチンに含めるだけで、原因不明のエラーによるシステム停止を大きく削減できます。

## フィルタリング、センサフュージョン、およびキャリブレーション

IMUのドリフト対策として、角速度を単純に積分するだけではバイアス誤差が時間の経過とともに蓄積していくため、マイコン上に離散化された一次IIRフィルタ（ローパスフィルタ）などを実装し、ノイズを低減するのが一般的な手法です。しかし、より高度な姿勢推定が要求されるドローンやロボットのシステムでは、加速度計、ジャイロスコープ、地磁気センサのデータを統合するセンサフュージョンアルゴリズムの導入が不可欠となります。

Madgwickフィルタや拡張カルマンフィルタを実装することで、ジャイロの累積誤差を加速度による重力ベクトルや地磁気による北方位で動的に補正し、より正確な空間姿勢（クォータニオン等）を算出することが可能となります。また、アルゴリズムの性能を最大限に引き出すためには、地磁気センサにおけるハードアイアン・ソフトアイアン誤差のキャリブレーションや、ジャイロの温度ドリフト補正など、事前の綿密な補正作業が必要不可欠です。計算過程においては、ENU（East-North-Up）やNED（North-East-Down）などの座標系を厳密に統一しておくことも、後々のバグを防ぐ重要なポイントです。

## レイテンシジッタの排除と時間軸の同期

センサを用いたリアルタイム制御システムにおいて最も警戒すべきは、通信の絶対的な遅延（レイテンシ）そのものではなく、遅延のばらつき（ジッタ）です。制御周期が一定でないことは、微分や積分を伴う制御系において致命的な不安定要因となります。

これを解決する有効な手法は、センサからデータを取得した瞬間にマイコンのハードウェアタイマーを用いた正確なタイムスタンプをデータ構造体に付与することです。上位のコンピュータへ転送される過程や、RTOSのタスクスケジューリングによって処理の遅延が変動したとしても、アルゴリズム内でこのタイムスタンプを利用して状態推定を行うことで、正しい時間軸を維持することができます。物理的な時間とデータの整合性を保証することが、精度の高いシステム構築の鍵となります。
