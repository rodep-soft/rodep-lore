# ROS 2におけるZenohとmicro-ROSの統合およびトランスポート層の評価

ROS 2の最新動向において、Zenohの統合はネットワークトポロジーの管理に革新をもたらしています。Zenohのインテグレーションでは、各コンテキストが単一のZenohセッションにマッピングされ、これがコンテキスト内のすべてのパブリッシャー、サブスクリプション、サービス、クライアントで共有される設計となっています。コンテキストはローカルのグラフキャッシュを保持し、ROS 2エンティティのネットワークトポロジーを追跡します。各エンティティの存在は、作成時に発行され破棄時に取り消される一意の「liveliness token（生存トークン）」を通じて管理されます。

組み込み用途では、micro-ROSのトランスポート層としてZenohを採用するアプローチが検討されています。ただし、標準のDDS実装と比較すると、実装の成熟度や対応バージョンにおいて確認が必要です。また、シビアなハードウェア制約がある環境では、単にmicro-ROSを利用するだけでなく、STM32等のマイコンにおいてHAL（Hardware Abstraction Layer）からLL（Low-Layer）APIへ移行し、DMAやハードウェアタイマーを直接制御することでパフォーマンスを向上させるという、より低レイヤーでの最適化が重要となる場面も多々あります。
