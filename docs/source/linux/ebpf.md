# eBPFによる革新的なオブザーバビリティ

近年のLinuxシステムにおけるパフォーマンス解析とトラブルシューティングの領域で、最も強力なパラダイムシフトをもたらしているのが eBPF (Extended Berkeley Packet Filter) です。
従来のカーネルモルのロードやソースコードの改変といった危険な手段を取ることなく、安全なサンドボックス環境でカーネル内の任意のイベントにプログラムをフックさせ、システム全体の挙動を極めて低いオーバーヘッドで観測することが可能になります。

ロボティクスなどのリアルタイム性が問われる環境では、「平均的な処理時間」よりも「稀に発生する数ミリ秒の遅延（テールレイテンシ）」が重大な不具合を引き起こします。このような事象に対し、eBPFツールフロントエンドである `bpftrace` や `bcc` ツール群（`execsnoop`, `opensnoop`, `biolatency` など）を活用することで、どのプロセスがどのシステムコールでブロックされているかをマイクロ秒単位のヒストグラムとして可視化できます。カーネルの任意の関数（kprobe）だけでなく、ユーザー空間のアプリケーション関数の実行（uprobe）にフックをかけることもできるため、分散システムの複雑な遅延要因を横断的に特定できます。

さらに、eBPFの応用はネットワーク処理にも及びます。XDP (eXpress Data Path) を利用すれば、ネットワークパケットがカーネルのプロトコルスタックに到達する前の、NICドライバの段階でパケットの解析や破棄（ドロップ）を行うことができます。LiDARなどから送出されるギガビット級の不要なマルチキャストパケットをハードウェアレベルに近い速度でフィルタリングすることで、CPUリソースの消費を劇的に削減するチューニングが実践されています。
