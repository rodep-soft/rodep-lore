# Language Comparisons

## プログラミング言語

### おそらく学ぶべき言語
#### C
全ての基本。仕様自体はシンプル。マイコンや低レベルのソフトウェアを記述するときに使う。高速だが安全でもモダンでもない。

#### C++
C言語にオブジェクト指向を追加した言語。基本構文はCと同じだが、実際のところCpp11以降のモダン構文を使うことが多いため、結構違う。ROS2で一番メインで使われる言語。これがないとロボットが動かない。高速、言語仕様はでかい。

#### Python 
ROS2でのもう一つの選択肢。実行速度が遅いが書きやすく、情報もライブラリも豊富。制御に使うことはさけるべきだが、テスト用のコードや画像認識周りでは非常に便利なので結構使う。

### 使えると役に立つかもしれない言語


#### JavaScript/TypeScript
Webで覇権取った言語。UI作成に便利なのと、汎用性はかなり高いのでやって損はないかなという言語。CppやRustほど速くないが、JIT芸でかなり高速化されている。

#### Rust
速いしモダンで将来性もありそう。ただ、ビルド遅い、構文が特殊、多言語ほどライブラリが揃ってない。あと環境構築もちょっと面倒。

### 他の有名言語について一言ずつ

#### Java
安定。冗長。Web等のシステムで企業がよく使う。

#### PHP
基本Webバックエンド用。Laravelで生き残ってる老人。

#### Ruby
珍しい日本初の言語。webで見るが人気下降中な気もしてしまう。

#### Kotlin
Android開発ならコイツ。Javaの後継。

#### Swift
iOS開発で使う。誰も覚えていないObjectiveCの後継。

#### Go
DevOps系ツールでよく使われてる。googleが開発したシンプルな言語。

#### Lisp
神の言語。関数型の走りみたいなやつ。

#### C\#
Javaに.Net付けたMicrosoftの巨人。Unityで使う。

## 言語パフォーマンスとメモリ管理の深層

システムプログラミングおよびアプリケーション開発における言語選定の基準について考察します。

### C++とRustのパフォーマンス比較

大規模なループ処理や複雑な計算において、C++とRustはどちらも極めて高いパフォーマンスを発揮します。最適化（`-O3`やリリースビルド）を施した状態では、RustはC++と同等か、特定のメモリ管理パターンにおいてはそれを上回る速度を記録することがあります。Rustはコンパイル時に借用チェッカーによってデータ競合を排除するため、ランタイムオーバーヘッドが少ないのが特徴です。一方、配列コピーなどのオーバーヘッドがRust側に存在する場合、V8エンジンなどによるJITコンパイルが強力に機能するJavaScript（Node.js, Bun, Deno等）が、特定のループ回数までは最適化の恩恵で逆転する現象も観測されます。

### ファイルシステムと抽象化

Linuxシステムにおいて、ファイルの本質はファイル名や拡張子ではなく「i-node（アイノード）」にあります。i-nodeはデータの実体ではなく、データが格納されているブロックを指すポインタの集合です。`cp`や`ln`の挙動を理解するには、このi-nodeの概念が不可欠です。ファイル名は単なるラベルに過ぎず、システムレベルでのデータ操作は常にi-nodeを介して行われます。

### GUIアーキテクチャの選定

フロントエンドおよびGUI開発において、TauriやFlutterが有力な選択肢となります。FlutterはUIとロジックが密結合しやすく、コードベースが肥大化する傾向があります。対してTauriは、バックエンドをRustで記述し、フロントエンドに任意のWeb技術を利用できるため、低レイヤーの処理（例えばシリアル通信や基盤データのBase64デコードなど）をRustに任せつつ、描画リソースを最適化するアーキテクチャの構築に優れています。
